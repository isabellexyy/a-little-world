# A Little World · 夜里的家

一栋手绘风格的小楼：亮着灯的九间房、可以散步的女孩，以及可点击的家具。

目前使用原生 HTML、CSS 和 JavaScript，无需安装 npm 依赖或构建。

## 在自己电脑上运行

用 VS Code 打开本项目文件夹，在终端运行：

```sh
python3 -m http.server 8765 --directory dist
```

浏览器打开 http://localhost:8765 。修改文件并保存后刷新页面即可。终端按 `Ctrl+C` 停止预览。

## 从哪里开始读代码

| 文件 | 作用 |
| --- | --- |
| `dist/index.html` | 页面结构、导航、设置和内容弹窗 |
| `dist/style.css` | 页面样式、家具高亮、图层顺序和小屏幕适配 |
| `dist/furniture.js` | 七件家具的位置、名称、图片裁切和点击内容 |
| `dist/routes.js` | 左右楼梯间与最短路线 |
| `dist/app.js` | 九间房的坐标、人物移动、逐帧绘制和遮挡 |
| `dist/character.js` | 走路图片分帧、对齐及摆臂素材合成 |
| `dist/camera.js` | 全屏铺满、拖动、缩放、边界回弹和导航 |
| `dist/assets/` | 楼房、人物、家具素材 |
| `.openai/hosting.json` | 当前 Sites 网站的发布配置 |

`dist/` 在这个项目里就是直接编辑的网页源码，名字虽然叫 dist，但不是自动生成的构建结果。

## 适合先尝试的小修改

- 改文字：打开 `index.html`；家具的「还在装修中」内容也在这里。
- 改字体、颜色或悬停效果：打开 `style.css`。
- 改家具名字、位置、大小：打开 `furniture.js` 的 `items` 数组。
- 改人物站位：打开 `app.js` 的 `rooms` 数组。`stand` 是横向站位，`foot` 是脚底高度。
- 看选路逻辑：打开 `routes.js`。跨层比较左右楼梯的总路程，进入后在同侧逐层上下楼。

场景坐标统一使用 **1536 × 1024**。画面适配屏幕时整体等比变换，调整家具位置时应使用场景坐标。

## 当前图层与素材

从后向前为：背景 → 后方人物 → 家具及室内遮挡 → 前方人物 → 外墙、窗框、树枝与窗帘 → 家具名称。

- 画室、书房、音乐室、收藏室、卧室：人物在家具前面。
- 厨房、餐厅、客厅、工作间：人物在家具后面。
- 收藏室人物高度为其他房间的 1.5 倍，并向下调整，使窗台遮住膝盖以下。
- 每个房间分别裁切人物，避免走过房间边界时整体切换图层。

主要素材：

- `house-furniture-empty.png`：移除七件独立家具后的背景。
- `house-clean.png`：完整无文字空景，用于保留原画的前景颜色。
- `foreground.png`：外墙、窗框、树和窗帘的透明遮罩来源。
- `furniture/furniture-sheet-v1.png`：正在使用的家具总图，由代码裁切。
- `girl-walk-sheet.png`：正在使用的人物步帧。`girl-arm-swing-sheet.png` 保留为旧素材，当前不加载。

## 和 Codex 一起修改

每次开始前先查看本地修改，再同步 GitHub 最新版本。若有未提交修改，先保存为一次提交或暂存，避免覆盖。

```sh
git status
git pull --ff-only origin main
```

完成修改、预览确认后：

```sh
git add README.md dist
git commit -m "Describe the change"
git push origin main
```

可以用 VS Code 的「源代码管理」界面完成相同操作。不熟悉的改动可以先使用新分支；尽量避免同时修改同一个文件。

## 肩线稳定与轻摆臂

`character.js` 的 `composeCharacter` 保留原腿部步序和过渡，头部、肩膀及中央躯干使用同一张站姿素材。肩线以下的袖子与手臂通过连续网格变形小幅摆动，避免不同生成帧的肩线跳动。摆臂与整套八步节奏同步，左右幅度不同以形成前后臂的轻微反向运动；启停时幅度平滑变化。不是简单增加生成帧数量。

可调参数：`swing` 中的 `18` 是素材坐标里的最大手部横向位移，`145` 是固定肩部区域下界。普通房间显示高度为 140，因此实际手部位移约 5 像素。

## 连续腿部步序

腿部采用 `[1,2,4,5]` 的着地／经过／另一侧着地／经过循环，不再在行走中插入站直帧或倒放半步。每个相邻姿势在整个区间用 smoothstep 混合，完整步周期与原来的摆臂周期一致。启停时同样平滑混合到站姿，上半身的固定肩线和轻摆臂算法保持不变。

为减少腿部淡入淡出重影，合成前按每行透明轮廓的 16 个分段匹配两帧，先把轮廓变形到过渡位置，再混合颜色。头部、肩膀和袖子仍使用上一版算法。
