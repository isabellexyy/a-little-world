# 夜里的家 · 第一版原型

无需安装依赖。用 VS Code 打开这个文件夹。

本地运行：

```sh
python3 -m http.server 8765 --directory dist
```

打开 http://localhost:8765 。

- `dist/index.html`：页面和控件
- `dist/style.css`：等比画面、手机和放大浏览样式
- `dist/app.js`：九间房坐标、人物平移、遮挡与暂停
- `dist/assets/house.png`：无人空景
- `dist/assets/foreground.png`：生成的前景透明遮罩来源
- `dist/assets/girl.png`：静止女孩透明素材

叠放：空景 → 女孩 → 用前景 alpha 从原画取色的遮挡层。这样保留原画外观，避免重绘前景覆盖底图。前景 alpha 仍需人工精修；家具尚未分层，人物可能穿过家具。当前用于测试移动、遮挡和相同比例坐标，不是最终动画。

房间按钮可点击或用 Tab / Enter 操作。点新房间时会先完成当前路段，再前往最近选择的房间。减少动态效果的系统偏好下默认暂停。小屏幕可看整栋楼，也可放大横向浏览。

下一步：确认人物比例与站位 → 精修遮罩 → 家具原位抠图和底图补洞 → 家具 hover 与内容面板 → 人物动作。

原图中的 about / explore 字样目前仍是画面文字，不是导航。

## 全屏探索更新

画面文字已移出图片：标题回中，about 打开简介，explore / 底部邀请语打开房间选择。

`dist/camera.js` 负责全屏等比铺满、有限墙面延伸、拖动/滚轮/方向键探索与边缘弹簧回弹。导航固定在视口；所有画面图层共用一个变换。画面设置中可切换整栋楼总览。减少动态效果偏好下回弹直接到位。

素材：`house-clean.png` 是无文字空景，`wall-texture.png` 是配套墙面纹理。边缘用轻微渐隐衔接，属于原型级延伸，不是完整重绘的楼体外立面。

## 场景边界修复

撤掉外接墙纹理及边缘渐隐。相机在完整原画内活动，预留 24px 回弹缓冲；最终绘制再按实际图像边界硬限制，因此拖动、滚轮、回弹、房间定位和尺寸变化都不能露出画外。画面设置改为拉近 / 恢复全景，不再缩小到露出整张图片外边缘。

## 家具交互

七件家具使用原始透明总图按固定坐标读取，浏览器裁去透明外边距后独立放置。请勿再使用早期裁切有误的 desk/piano 等独立文件。新底图 `house-furniture-empty.png` 已移除对应家具，避免重影。

`furniture.js` 管理位置、名称、高亮与内容面板。悬停/键盘聚焦显示名称和暖色描边，轻微放大；点击/Enter 打开原生 dialog，支持关闭按钮、Esc 与点外部关闭，关闭后返回焦点。打开任意面板时暂停人物动画，关闭后恢复原先播放状态。家具层在前景遮挡下面。素材是生成补画版本，部分比例和原画不同，可继续调位置和大小。

## 女孩走路动画

`assets/girl-walk-sheet.png`：内置 ImageGen 生成，4×2 透明精灵图，第一格站姿、其余七格走路。肩上短发有刘海，宝蓝开衫、奶油黄内搭、牛仔裤、珊瑚鞋。`character.js` 按网格读取、统一脚底基线和躯干中心；`app.js` 按实际移动距离推进步帧（每8场景像素换一格），左右共用素材并水平翻转。停步用第一格，暂停保留当前步帧，墙内换层不显示人物。已保持现有家具和外墙遮挡。

## 步伐稳定修复

各帧单独归一化身高；统一头部/上半身，腰部混合以避免生成帧脸部和头发跳动。使用 [0,2,1,2,0,5,4,5] 步序，每11场景像素推进一格，末35%做短交叉过渡（加法合成避免重叠透明度闪烁）。移动起止15%加减速。此版本选择克制的上半身，不再使用不一致的摆臂帧。

## 摆臂与逐层路线

头部稳定遮罩收至颈部，恢复原始步帧的胳膊摆动；腿部步序、间距和混合保持不变。

`routes.js` 是独立路线生成器。同层直接穿过相邻房间；跨层先沿当前层走到较远的一端，在楼体外侧隐藏的楼梯区域用1.8秒到相邻层。如果还要跨一层，先穿过整层走到另一端再上下楼，最后走到目标房间。楼梯边界采用场景坐标，不随视口或拖动改变。检查过全部81个起终房间组合：楼梯仅连接相邻层、上下楼不改变横坐标、同层无传送且终点正确。

## 修正入口方向与整臂摆动

目标房间在当前位置左边时，先向左走到楼体边缘上/下楼；在右边则走右侧。已专项验证卧室到厨房：沿底层经过收藏室、从左侧楼梯升一层、再从厨房左边进入。

`girl-arm-swing-sheet.png` 是补画的肩膀/上臂/前臂完整摆动素材；character.js 仅把颈部以下至上腿的区域混合进旧帧，头部和下腿保留原版。腿部步序与过渡节奏未改。
